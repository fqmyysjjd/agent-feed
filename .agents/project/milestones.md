# Project Milestones

This file defines the current implementation milestone route for Agent Feed.

## Default Route

1. M0: Working CLI prototype and standard template.
2. M1: Robust validation and Python/Node template profiles.
3. M2: Codex, Claude, Cursor, and Windsurf adapters.
4. M3: Brownfield project discovery and guided initialization.
5. M4: CI integration, update/migration flow, and release packaging.

CLI command behavior, template responsibility model, and generated file layout are serial integration surfaces unless explicitly split with disjoint write sets.
