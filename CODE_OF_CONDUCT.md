# Code of Conduct

Agent Feed is a developer tool for improving AI-assisted software engineering. Contributions should keep discussion practical, respectful, and focused on making the project more reliable.

## Expected Behavior

1. Be clear and specific when reporting issues or proposing changes.
2. Critique ideas, code, docs, and workflows rather than people.
3. Assume contributors may use different AI tools, editors, operating systems, and development setups.
4. Keep examples and generated instructions safe for public repositories.
5. Disclose relevant conflicts or security concerns when they affect a proposal.

## Unacceptable Behavior

1. Harassment, insults, or discriminatory language.
2. Publishing private information, credentials, or user data.
3. Encouraging destructive automation without clear user consent and recovery guidance.
4. Repeatedly derailing technical discussions after maintainers have redirected the thread.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or other contributions that violate this code of conduct. Serious or repeated violations may result in temporary or permanent restriction from project spaces.

## Reporting

Report conduct concerns through the repository owner's GitHub profile contact method. For security-sensitive reports, follow [SECURITY.md](SECURITY.md).
