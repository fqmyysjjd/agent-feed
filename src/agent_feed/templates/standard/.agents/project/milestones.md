# Project Milestones

This file defines the current implementation milestone or phase route for {{PROJECT_NAME}}.

Replace this template with project-specific phases.

## Default Route

1. M0: Project skeleton and tooling.
2. M1: Public contracts and core abstractions.
3. M2: First vertical runtime/application slice.
4. M3: Integration and failure paths.
5. M4: Durable storage or production hardening.

Shared contracts and public API are serial integration surfaces unless explicitly split with disjoint write sets.
